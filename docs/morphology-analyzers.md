# Морфологические анализаторы арабского: что можно взять в офлайн-приложение

Все варианты ниже проверены по первоисточникам (сайты проектов, PyPI, каталог LDC) на ноябрь 2026.
Ключевой критерий — «без бэкенда»: анализатор должен работать на телефоне, без сети и без заявок.

## Сводка

| анализатор | где взять | лицензия | одобрение / оплата | запуск на Android |
|---|---|---|---|---|
| **CAMeL Tools** (NYUAD) | `pip install camel-tools` | код MIT; базы: `calima-msa-r13` **GPL-2**, `calima-egy-r13` GPL-2, `calima-glf-01` CC BY 4.0 | **нет**, скачивается сразу | Python + Rust-сборка → напрямую нет, нужен Chaquopy/порт |
| **AlKhalil Morpho Sys 2** (Университет Мохаммеда I, Ужда) | SourceForge `alkhalil` | **GPL-3.0** (Java) | **нет** | **да, это Java** — ложится на Android напрямую |
| **farahidi** / **farahidi-js** | `pip install farahidi` / npm | **GPL-3.0-or-later** (порт AlKhalil 2) | **нет** | Python-порт (Chaquopy) или JS-порт в WebView; словарь внутрь колеса ~11 МБ, офлайн |
| **Aramorph** 1.2 | SourceForge `aramorph` | GPL (эталон Buckwalter) | **нет** | да (Java), но качество ниже |
| **Farasa** (QCRI) | farasa.qcri.org, GitHub | **только для исследований**; для коммерции — письмо авторам | веб-API: бесплатно, но **регистрация**; коммерческое использование — по договорённости | офлайн-сборка есть, но лицензия не для продукта |
| **SAMA 3.1 / BAMA 2.0** | каталог LDC (LDC2010L01, LDC2004L02) | members-only agreement | **платно + заявка**, членство LDC | технически да, юридически — нет |
| **MADAMIRA** | Columbia | требует базу SAMA | фактически тянет за собой лицензию LDC | да |

## Что это значит на практике

1. **Бесплатно и без заявок — есть, и этого достаточно.** AlKhalil 2 (Java, GPL-3) и CAMeL Tools
   (Python, MIT-код + GPL-2-база) — оба скачиваются сразу, обе без регистрации. Farasa бесплатен
   только для research, SAMA/BAMA/MADAMIRA требуют денег и членства в LDC.
2. **Для Android нативной сборки реальный выбор — AlKhalil 2**: это Java, кладётся как модуль,
   ничего не надо переписывать. CAMeL Tools на телефоне — через Chaquopy (Python внутри APK)
   либо через порт; farahidi-js — если попадём в WebView.
3. **Лицензия важнее качества.** Обе бесплатные опции — GPL (AlKhalil 2 — GPL-3, база CALIMA —
   GPL-2). GPL-данные в APK означают, что приложение должно быть GPL-совместимым: либо открываем
   исходники (что совпадает с решением «публичный репозиторий = движок»), либо не берём GPL-базу
   и остаёмся на собственных правилах аффиксов.
4. **Что анализатор реально даёт.** По нашим замерам слабое место — глагольные формы и клитики:
   пайплайн «лемма → KSAA» выиграл ровно на `يحتاج`, `نستطيع`, `تنطوي`, `تستقيل`. Ожидаемый
   прирост от настоящего анализатора — не «всё сразу», а покрытие словоформ (порядка +5…10 п.п.
   к доле найденных), при этом выбор смысла он не решает.
5. **Порядок действий**: сначала кросс-подтверждение (уже измерено: 68% на 188 словах), затем
   фильтр однословных статей и кандидаты — и только потом анализатор, потому что анализатор
   улучшает *поиск слова*, а не *выбор значения*.
