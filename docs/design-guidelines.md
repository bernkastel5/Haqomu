# Design guidelines (no AI-slop)

Принято 2026-11-14 как обязательное ограничение для всех UI-работ в приложении.
Источник: файл пользователя «human-like design skill.txt», приведён дословно.

```
Adhere to these rules so design won't be seem as obviously vibe-coded

No lucid icons
No emojis
No liquid glass
No em dashes
No inter/ geist / space grotesk
No "3 feature cards in a row" pattern
No bento grids
No terminal window
No "it's not X, it's Y" pattern
No purple & black composition
No radial orbs
No dot grids
No sparkle icons
No animated arrows
No hover animations
No rainbow coloring```
