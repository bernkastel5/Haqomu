# ADR 0009: FTS-индекс в паке необязателен

Статус: принято 2026-11-14

## Контекст

На телефоне установка Hans Wehr и Kaikki падала с ошибкой
`no such module: fts5 (code 1 SQLITE_ERROR)`, Camel проходил. Причина — наш же формат:
`AndroidPackWriter` создавал `sense_fts` строкой
`CREATE VIRTUAL TABLE sense_fts USING fts5(...)`, а системный SQLite в Android
собирается без FTS5 (обычно есть только FTS3/FTS4). При этом:

- поиск в попапе идёт по `entry.head_norm` (`AndroidPackDictionary`), FTS-индекс
  **не используется вообще** — ни одного `MATCH` в коде;
- `PackChecks` требовал наличия `sense_fts` и читаемости модуля, то есть проверка
  отвергала паки по причине, которая не влияет на работу приложения;
- ошибка вылезала в конце долгой конвертации (Kaikki — сотни тысяч строк), уже после
  скачивания и обработки — самое дорогое место для отказа.

Требование FTS5 пришло из `docs/architecture.md` §4; менять архитектуру «в сторону
усложнения» нельзя, но и держать обязательным индекс, который на целевой платформе
недоступен и не нужен, нельзя.

## Решение

1. `AndroidPackWriter` пытается создать индекс по убыванию возможностей:
   **FTS5 → FTS4 → без индекса**. Вид пишется в `meta('fts')` = `fts5` / `fts4` / `none`.
   Вставка в индекс делается только если он создан (`insFts` — nullable), остальной код
   пака не меняется.
2. `PackChecks`: `sense_fts` больше не обязательная таблица. Если пак заявил индекс
   (`meta.fts` = fts5/fts4) — таблица должна читаться на этом устройстве; если заявил
   `none` или ключа нет (паки, собранные раньше) — проверка проходит с пояснением
   «без FTS — поиск по head_norm».
3. Внешний контент (`content='sense'`) сохраняется: копий определений в индексе нет,
   пак от индекса не тяжелеет.

## Последствия

- Hans Wehr и Kaikki собираются и устанавливаются на любом устройстве; на Android
  индекс, скорее всего, будет `none` или `fts4` — на попап это не влияет.
- Если однажды понадобится полнотекстовый поиск по определениям, честнее положить
  рядом обычную таблицу с инвертированным индексом или подключить SQLite с FTS5
  (увеличит APK). Тогда `meta.fts` уже позволит отличить старые паки.
- `docs/architecture.md` §4 остаётся как есть (FTS5 — желаемый вариант), фактическое
  поведение описано здесь и в `PROJECT_STATE`.
