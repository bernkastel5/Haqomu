# ADR-0006: Порт конвертеров Kaikki и Hans Wehr на устройство + мастер установки

**Статус:** принято (2026-11-14). Эталоны: `tools/build_kaikki_index.py`, `tools/build_hw_pack.py`.

## Контекст
Заказчик: «все конвертеры довести, пользователю только кнопки нажимать — мастер всё сам ставит».
Исследованы получение и формат источников:

- **Hans Wehr** (`GibreelAbdullah/HansWehrDictionary`, assets/hanswehr.sqlite, 4-е изд., OCR):
  прямой raw-URL, лицензия — текст охраняется авторским правом: только личное использование,
  распространение запрещено. Мастер скачивает у источника, ничего не раздаём.
- **Kaikki** (`kaikki.org/dictionary/Arabic/kaikki.org-dictionary-Arabic.jsonl.gz`, ~72 МБ gz,
  233k статей, CC BY-SA 4.0): скачивание у источника разрешено с атрибуцией и ShareAlike.
- **KSAA** (siwar.ksaa.gov.sa, `Result/SearchEntriesWeb?word=`): официального API/дампа нет,
  условия использования запрещают копирование всего معجم («لا يجوز نسخ محتوى المعجم كاملًا»).
  **Конвертер/пак KSAA невозможен** — это онлайн-источник on-demand; в мастере — только
  информационная строка. Зеркало или «KSAA-пак» не делаем и не предлагаем.
- **CAMeL calima-msa-r13** (D-019): официальный zip релиза CAMeL-Lab (camel-tools-data,
  2022.03.21, 40.5 МБ, GPL-2). Zip: `morphology_db_calima-msa-r13-0.4.0.zip`.

## Решение
Единый формат пака §4 (`meta/entry/sense/sense_fts`, FTS5, `schema_version=1`) — как в архитектуре;
эталонные поля источников маппятся так:

### Kaikki → §4
- статья = строки JSONL с арабским `word` (`isArabicWord`: все буквы в U+0600..U+06FF, включая пробел);
- ключ `head_norm` = эталонная нормализация (снятие огласовки/татвиля, унификация алифа/йа/та-марбуты);
- смыслы = все смыслы, не помеченные `obsolete/archaic/no-gloss`, без глоссов
  `form of / verbal noun of / plural of`; если подходящих нет — первый непустой глосс
  (поведение `pick_gloss`); смыслы сохраняются ВСЕ, по порядку (Ф9), `entry.pos` сохраняется;
- `root` из категорий `Arabic terms belonging to the root …` (пробелы убраны);
- точный дубликат (`head_norm|pos|все глоссы`) пропускается;
- **словаформы (`forms`) и `form_of`-указатели не переносятся**: в §4 нет таблицы форм,
  поиск идёт по `entry.head_norm`; это осознанное отличие от эталона (индекс form→lemma
  нужен деинфлектору и вернётся вместе с ним, отдельным ADR).

### Hans Wehr → §4
- источник `DICTIONARY_content(id, c1=word, c2=definition, c3=is_root, c5=quran)`;
- разбор `definition` портирован 1:1 (`HwPolicy.parseEntry`): headword/огласованная голова,
  транслитерация (Latin-токен после заголовка, не из ROMAN_STOP), породы `<b>I..X</b>`,
  `pl.`-числа (300 символов), блок идиом после `│`, альтернативный корень в арабских скобках;
- чистка (`cleanBody`): номера страниц (2–4 цифры), надстрочные цифры у латиницы, `; ;`,
  пустые скобки, ведущий `and `, **породы `<b>I..X</b>` удаляются целиком** (уходят в
  `tags`), прочие `<b>` снимаются;
- корни: `is_root=1` + арабское слово без пробела 2–5 букв (выбор замером, build-report.md);
  каждой некорневой статье достаётся ближайший предшествующий корень (`rebuild_roots`);
  `root` кладём нормализованным ключом;
- **xref/xref_alpha/empty пропускаются** (в §4 нет `see_entry_id`; глухие заглушки в попапе
  бесполезны); статьи без осмысленного `body` пропускаются;
- **`forms`-индекс не переносится** (нет в §4); отчёты/спот-чек эталона не переносятся
  (исследовательская часть); `kind` (root/word) не переносится — различается только через `root`;
- `entry.id` сохраняет id источника.

### Мастер установки (D-019)
`ui/PackWizardSection` на экране «Импорт паков», над списком установленных:
- кнопка «Установить всё» (+ повтор шага при ошибке), флажок согласия с условиями источников
  (CAMeL-Lab GPL-2, Hans Wehr личное использование, Kaikki CC BY-SA 4.0) — без него кнопка неактивна;
- шаги: CAMeL (скачивание zip → конвертация на устройстве → подмена `filesDir/camel_pack.sqlite`),
  Hans Wehr (скачивание hanswehr.sqlite → конвертация → `PackChecks` → `packs/hanswehr.sqlite`),
  Kaikki (скачивание jsonl.gz → конвертация → `PackChecks` → `packs/kaikki.sqlite`);
- прогресс: скачивание (байты/%), конвертация (строки), проверка; ошибки шага не отменяют остальные;
- временные файлы удаляются; установка пака — копия в `packs/<name>.sqlite` (подмена безопасна:
  сначала `.tmp`, потом rename);
- KSAA — информационная строка (ставить нечего, онлайн-источник);
- требуется `INTERNET` в манифесте; приложение само ничего не раздаёт.

## Последствия
- Фаза 4 закрыта по конвертерам: calima (ADR-0005), Hans Wehr, Kaikki — портированы и
  собираются на устройстве; KSAA — онлайн-источник по условиям лицензирования.
- Поиск по §4-пакам в попапе — фаза 5 (будет читать `entry.head_norm` + `sense_fts`).
- Проверка на реальном HW/Kaikki дампе — на устройстве пользователя (файлы не входят в репозиторий,
  как и у эталона); синтетика — JVM-тесты `HwPolicyTest`/`KaikkiPolicyTest`.

## Постскриптум (CI-отладка и рантайм-баг)
- `SQLiteDatabase.execSQL` компилирует **только первый** SQL-стейтмент. Многостейтментный
  `SCHEMA` молча создавал бы лишь таблицу `meta` — `AndroidPackWriter` и `AndroidCamelPackWriter`
  создают схему по одному стейтменту (`SCHEMA_STATEMENTS`). Ошибку CI не ловит (путь Android-writers
  исполнялся только на устройстве) — найдена при аудите инфраструктуры после красного прогона.
- Прогоны 94ab476…fb00b50 красные; причина вычислена бисекцией без доступа к CI-логам
  (CDN `results-receiver.actions.githubusercontent.com` недоступен из среды): откат к заведомо
  зелёному дереву, затем покадровое восстановление дельты пушами. Корень — один ассерт
  `parseEntry_altRootFromArabicParens` (ожидал `altRoot="قوم"` при одиночном токене-скобке;
  эталон `is_arabic_token("(قوم)")==true`, т.е. скобка уходит в заголовок, alt_root не заполняется).
  После приведения теста к эталону — полный прогон **43582399262** ✅.
- Репозиторий CI-логов и корпоративный кэш `gradle-home` нестабильны (400 при restore) — не фатально;
  чат GitHub App не имеет права `workflows` (Workflows permission), поэтому `.github/workflows/*`
  менять нельзя — диагностика красного CI делается только бисекцией коммитами.
