## 1. Проект одной строкой

**Haqomu** — Android-приложение (Kotlin): выделяешь арабское слово в любом приложении →
пункт «Словарь» в меню действий (`ACTION_PROCESS_TEXT`) → офлайн-попап со значением →
кнопка «В Anki». Аналог Yomitan под арабский. Без сервера, без счётчиков, без рекламы.
Источники истины по убыванию приоритета: **решения заказчика (§6, §8 этого файла)** →
`docs/TZ.md` (v1.0) → `docs/architecture.md` → `docs/handoff.md`.
